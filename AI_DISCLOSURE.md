# AI disclosure

Find Me Clientside's Java implementation, build setup, translations, documentation, and release
text were substantially generated using OpenAI Codex, with direction and in-game testing from
the maintainer. The project should be described as primarily AI-generated, rather than merely
using AI for spelling corrections or occasional code completion.

The mod does not use generative AI at runtime and does not call an AI service. Its storage cache
and rendering run locally on the Minecraft client.

The icon is an existing Lucide `package-search` graphic. Its SVG geometry was downloaded unchanged
from the upstream project; PNGs are ordinary format/size exports. The screenshots are actual
Minecraft screenshots captured during development. No text-to-image model or generative image
editing was used for these assets. See [asset provenance](assets/branding/PROVENANCE.md).

The project is inspired by Buuz135's FindMe. Our client-side caching implementation and AI usage
should not be attributed to Buuz135 or presented as an official FindMe release.
